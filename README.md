# Sudocrime

Deduction game mixing Sudoku logic with murder mystery. 60 cases in three difficulty tiers.

**Play online:** Open `murder-sudoku.html` in your browser.

## Features

- 60 cases, easy to hard
- No internet needed — works fully offline
- No ads, no tracking, no data collection
- Privacy-first: all progress saved locally on your device

## Languages

- Español / English (toggle in-game)
